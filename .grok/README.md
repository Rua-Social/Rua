# .grok/

Harness adapters so Grok finds Rua skills and workflows. Not doctrine
and not an org chart.

- `skills/` — symlinks into `00-system/skills/`. Doctrine lives there.
  Do not write a second copy of a skill in this folder.
- `workflows/` — repeated parallel passes. The first is `desk-brief`.
  Add another when the same multi-agent handoff is happening every
  week. See `20-studio/desk.md`.
