# 10-clients

One directory per client. Each client directory follows the same phased
structure so any project can be picked up without relearning the layout:

```
00-brief/       What the client asked for
01-research/    Research and context gathering
02-plan/        Shoot plans, concepts, schedules
03-production/  Shoot-day material
04-post/        Edit and post-production
05-delivery/    Final assets and handover
```
