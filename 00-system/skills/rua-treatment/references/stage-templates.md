# Prose treatment template

This is a working shape, not a mandatory page count. It covers treatment prose
and packaging. Script, storyboard, and visual-aid shapes are written with the
founder on the first real use of each. A treatment package does not include them.

## Internal working draft

```
TITLE

[Plain prose. One idea per paragraph. Describe the progression of the film,
including what is visible and where sound comes from. Proposed beats may appear
here so the film can be read aloud.]

Agreed
- [Beat] — [source: brief, call, or a choice already made]

Open
- [Only a question whose answer changes the film]

Proposed
- [Beat in the prose that the source did not give]
```

## Prose treatment

Use this once the founder is packaging an agreed film. Drop the working lists.
Keep a question only when its answer still changes the film.

```
TITLE

[Plain prose. One idea per paragraph. Describe the progression of the film,
including what is visible and where sound comes from. Keep named instance facts
in the job's vault record, not in reusable doctrine.]

Open questions
- [Only a question whose answer changes the film]
```

Checks:

- The purpose and spine are clear early.
- The treatment can be understood without a script table.
- Every agreed beat names a source. Anything else is under Proposed.
- Unapproved options remain separate.
- A package of treatments does not imply a recommendation, script or cast.
