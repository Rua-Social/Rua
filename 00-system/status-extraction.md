# Studio status extraction

Use for a factual account of Rua's present work, decisions or outstanding items.
Start with the scope and date requested. Read the relevant studio records;
`20-studio/todo.md` holds founder next-actions. Retrieve named engagement facts
through `rua vault search` and `rua vault get`. Current Workspace facts require
a live lookup under `AGENTS.md`.

Return each relevant fact with its source and date when available. Separate
recorded decisions, work confirmed complete, pending work and unknown status.
A plan, draft or old note does not prove completion. Where sources conflict,
show the conflict and dates rather than silently choosing a convenient version.
Do not infer revenue, consent, delivery or client approval from absence of a note.

Extraction is read-only: return findings in the conversation unless the user
requests a file. Follow any requested format or length limit. If the source is
unavailable, identify the gap and complete the supported parts.
