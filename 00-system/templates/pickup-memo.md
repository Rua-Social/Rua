# Pickup memo

Use for a short assessment of a pickup opportunity. Read the supplied scope and
relevant evidence. Keep it in the conversation unless a file is requested.
Use the user's requested length; eight lines applies only when requested.

Cover the opportunity, what the material shows, the intended audience response,
the useful capture or edit, the agreed finish, and any decision still needed.
For a “feed versus feelgood” request, assess those two purposes using the supplied
material. Label possible approaches as proposals and leave creative selection
to the founder. Omit sections that add nothing to the question.

Use `00-system/communication.md`. Derive facts from this engagement and keep the
memo within its scope. A pickup memo does not initiate a content sprint.
