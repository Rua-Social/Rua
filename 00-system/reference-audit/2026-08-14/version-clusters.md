# Version clusters

Likely file families, grouped on normalised filename, date token, path and logical size.
**Nothing here is deleted, collapsed or declared superseded.** Files were not hashed, so
byte-identical duplicates are inferred from equal size plus equal name stem and are marked
as *probable* only. Dated variants are preserved deliberately: the sequence is the evidence
of how the visual approach moved.

---

## Gaps in the version record

These are absences, recorded as evidence in their own right.

1. **No HTML source survives for the Skehans concepts deck after 26 March, for any
   schedule, or for the shot list.** Only PDF exports remain. The design system lives in
   CSS, so for four of the six deliverables the *build* is only recoverable by reading a
   rendered page, not the source.
2. **`skehans_shot_list_250526.md` does not exist anywhere on any scanned root.** The only
   shot list artefact recovered is `shot list skehans 29052601.pdf` (7.8 MB, 28 May) — a
   PDF roughly 240× the size of a markdown shot list, so almost certainly image-bearing
   and structurally unlike what the skill describes.
3. **Three of the five filenames the current skill names do not exist as named.**
   Recovered as named: `skehans_week0.html`, `skehans_handover_jun2026.html`. Recovered as
   a different format: `skehans_concepts_250526` (PDF, not HTML),
   `skehans_schedule_250526` (PDF, not HTML). Not recovered in any form:
   `skehans_shot_list_250526.md`.
4. **`references/creative-library.md` is cited five times across the skill and does not
   exist in the repository.** Nothing resembling it was recovered on disk either.
