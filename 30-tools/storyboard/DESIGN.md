# Storyboard appearance

Preserve the existing cream paper, dark green headings, serif display titles,
sequence colours and image-led cards. The migration changes where branding
comes from, not the board's visual hierarchy.

Desktop uses a three-column board, with a panel drawer for detailed editing.
Small screens collapse to one column. Presentation centres the frame with
direction, sound and playback controls below. Video export has its own controls
and preview surface.

Project labels and story-specific introductory copy come from configuration.
Use plain text for those values. Notices about browser storage and source
versions stay visible near the toolbar, separate from creative content.
Keep keyboard focus indicators, labelled controls, modal navigation and the
skip link when changing the interface.
